# 🧠 Memory Matrix Game

An interactive, responsive 3D card matching game built with HTML5, CSS3 transitions, and vanilla ES6+ JavaScript.

---

## ✨ Features

- **3D Card Flip:** Smooth 3D perspective flip animations on a responsive 4x4 grid.
- **Game Engine:** Fisher-Yates shuffle with strict card matching logic and board-locking guards.
- **HUD & Score Tracking:** Real-time move counter, elapsed timer, and persistent personal best record.
- **Victory Modal:** Pop-up celebration with final statistics and instant restart.

---

## 🎯 How to Play

1. Click any card to reveal its symbol and start the timer.
2. Select a second card to find its match.
3. Matched pairs stay revealed; mismatches flip back after 1 second.
4. Match all 8 pairs in the fewest moves and fastest time!
